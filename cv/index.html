Specialises in lakehouse modernisation, lineage, reliable pipelines and AI-assisted migration across financial services, UK consulting and the public sector.

  • Cloud and delivery: AWS production projects; GCP metadata/CDC prototyping; Azure Databricks workshop and lab development; Docker, Git and CI/CD practices.
