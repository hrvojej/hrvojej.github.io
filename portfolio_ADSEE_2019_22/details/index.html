Project in depth

Applied computer vision, analytics and data-science education

Developed an applied computer-vision teaching case for ADSEE at Algebra / Algebra LAB. Four connected Jupyter notebooks turn video into sampled images, object detections, face crops and analytical tables, with exercises that let learners change parameters, inspect results and understand the limits of pretrained models.

Client / context
Erasmus ADSEE · Algebra / Algebra LAB
Period

My contribution and the practical question

The retail/marketing case explored how street video can be turned into structured observations of activity. My work combined software integration, data preparation, analytical views, presentations and practical exercises. It connected a business question with the actual steps needed to produce and inspect model outputs.

The case used pretrained computer-vision models and existing libraries. The engineering contribution was the connected workflow and its teaching and analysis tools, including turning detections into usable records. The notebooks explicitly distinguished using a trained model from training a new one.

Four notebooks and their outputs

Organised the case as a sequence with inspectable intermediate outputs. Learners could revisit a previous stage when poor input quality or detector settings affected a later result.

Video sampling and a repeatable teaching exercise

The first notebook provides a short-video exercise and a worked Barcelona street-video example. It uses youtube-dl for retrieval and a FrameExtractor helper to inspect duration, estimate the number of samples and save images at a specified frame interval.

For the 60-fps example, every 300th frame corresponds to one image every five seconds. The approximately 11-minute recording produced 133 sampled images in the worked example. Learners first use their own short clip and then inspect the prepared example.

The notebook names the output folders and image prefixes, separates practice output from prepared material, and includes an image-folder viewer. The frame-extraction helper is identified in the notebook as adapted from an external example; the portfolio does not claim that helper or the pretrained models as original algorithm research.

Object detection: from images to individual records

The supplied notebook loads ImageAI’s object-detection interface and a pretrained resnet50_coco_best_v2.1.0.h5 model. It passes input and output directories to a detection helper and receives a tabular collection of detected objects.

The output structure includes an annotated source image and a separate folder of cropped objects for that image. A learner can therefore compare the detected class and probability with the actual crop and the wider scene.

The case handles examples such as people, bicycles, cars and bags. It retains the location in the source video so that a tabular finding can be related back to when it occurred, rather than becoming an isolated image label.

DataFrame, Excel and image-enriched HTML

Converted detection output into a pandas DataFrame and exported it to Excel. Added an image column by generating thumbnails from each detected object’s stored path, then rendered an HTML table with those thumbnails embedded.

This gave the same result three useful forms: structured data for further calculations, a familiar spreadsheet for inspection, and a visual table for checking whether a detection made sense. The corresponding presentation explains the parameters and output files alongside the code.

Interactive exploration with qgrid and pivot tables

Added qgrid controls for filtering the result table by class, probability and video time. The exercise asks learners to combine filters to select person detections within a chosen interval and above an 80% detector-probability threshold.

The filtered DataFrame can be rendered again with image thumbnails. This keeps the analytical selection connected to visible evidence rather than showing only a count.

Integrated pivottablejs for exploratory grouping and pivot views. The wider presentation material includes charts by object class. These are teaching and inspection tools over detections, not a validated count of unique people across the video.

Face detection and parameter experiments

The third notebook uses OpenCV’s pretrained frontal-face Haar cascade. Images are converted to grayscale, and detectMultiScale returns the position and dimensions of candidate face rectangles.

The teaching sequence starts with permissive detection, draws the resulting rectangles and then changes scaleFactor, minNeighbors and minSize. It compares small candidate regions with larger face crops and makes false positives visible.

Worked settings include a scale factor of 1.05, nine neighbours and minimum sizes of 40×40 and 100×100 pixels. The batch discussion also records increasing the neighbour threshold to reduce incorrect detections. These are examples for the sample images, not universal optimal settings.

The chosen configuration is applied across the image folder, and extracted faces are saved for inspection. Learners discuss how camera position, distance, frontal visibility and crop size affect the available data.

Pretrained age/gender model integration

The fourth supplied notebook uses an OpenCV face detector together with pretrained Caffe age and gender networks. It defines the model configuration and weight files, the model’s eight age bands and its two gender-class labels.

For each detected face, the implementation extracts a crop with padding, prepares a 227×227 input blob, invokes the network and selects the highest-scoring output. It writes the crop and associates the result with the source image.

The result records include image path, estimated age band, model gender label and detector confidence, followed by thumbnail-enriched HTML and pivot analysis. Detector confidence and attribute-prediction correctness are different quantities; the page does not present these outputs as verified personal facts.

DeepFace/FaceNet and YOLO also appear in the broader project and presentation record as experimental tools. The four supplied notebooks document the ImageAI/OpenCV/Caffe teaching implementation described here.

Teaching model limitations through visible examples

The face-detection material deliberately shows false positives and missed or unsuitable faces. Parameter changes make the trade-off observable: stricter settings can remove bad detections while also reducing the number of usable faces.

The attribute-analysis stage is an experiment with existing models. Image quality, pose, distance and the models’ categories constrain the interpretation. The educational outcome was understanding the workflow and its limitations, rather than claiming reliable demographic measurement or a production surveillance service.

Learning materials and the Jupyter environment

Prepared the four notebooks with explanations, code cells, exercises, intermediate views and accompanying presentations. Set up a local Jupyter server on Algebra infrastructure for demonstrations and student use.

The lesson structure links problem definition, data selection, technique selection, model application, result analysis and discussion. A proposed LMS/Jupyter arrangement separated course reading and presentations from interactive code and practical work.

The notebooks use reusable helper functions for image browsing, detection, cropping, thumbnail rendering and spreadsheet export. This gives learners a consistent way to inspect intermediate images and analyse the resulting tables.

ADSEE context and educational delivery

ADSEE was an Erasmus+ collaboration involving Algebra, the University of Amsterdam, the German National Library of Science and Technology (TIB), the Faculty of Information Studies in Novo mesto and Arctur. It developed applied data-science teaching materials for higher education and business use.

The project published its educational materials in November 2021 and identified Algebra as the authoring institution for the Retail/Marketing module. My involvement, recorded for November 2019 to March 2022, joined the technical case with its educational explanation and dissemination.
