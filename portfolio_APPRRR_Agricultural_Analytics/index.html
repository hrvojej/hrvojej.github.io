SQL reporting and Tableau delivery

Developed complex SQL views to prepare agricultural data and built Tableau dashboards for analysis across Croatia’s Ministry of Agriculture and its Paying Agency for Agriculture, Fisheries and Rural Development (APPRRR).

The work covered database transformations, preparation of reporting data and dashboard development. Tableau used a large Hyper extract covering a broad range of the agency’s data.

Agricultural-finance reference model

Prepared Tableau source definitions over SQL Server reference data covering categories, types, funds and funding sources. A reference-data workbook combined seven source tables through a union and retained the originating table name alongside the shared fields.

The model included identifiers and codes, Croatian and general names, parent relationships, category/fund/source references, active and deleted flags, and creation/modification dates.

The reference workbook contained its own Hyper extract and a worksheet displaying Croatian names and codes. It was one component of the broader SQL and dashboard development.
