Multi-agency data pipelines for labour-market analytics

Built the data collection and preparation jobs used to combine records from Croatian ministries and agencies for the labour-market portal.

Client / context
Croatian Ministry of Labour, Pension System, Family and Social Policy
Period
During the Algebra / Algebra LAB engagement
My role
Lead Data Engineer / Developer
Key contribution

Wrote Python and SQL jobs to obtain data from APIs, files and database exports, clean and restructure it, and load the analytical warehouse on a schedule.

Different sources and delivery patterns

Collected data from key Croatian ministries and agencies. Implemented REST/API acquisition, including the GSD interface, JSON handling, downloaded files, database exports, CSV dumps and SFTP deliveries.

From import to the analytical warehouse

Developed Python and SQL processing to clean and restructure inputs. Mapped source formats into import, staging and DWH layers and used SQL procedures for further processing.

Prepared ETL pipelines and execution schedules with Microsoft SQL Server and Oracle in the processing environment.

Contribution to the public-service outcome

Prepared integrated analytical data for the Croatian labour-market portal by bringing ministry and agency sources into consistent warehouse structures and scheduled processing flows.
