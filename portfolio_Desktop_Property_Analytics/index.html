Desktop property-ad analysis and notifications

Developed a PyQt5 desktop application that turned property advertisements into a filterable table and notified users about new listings matching their search criteria.

Client / context
Independent software project
Period
Independent development
My role
Lead Data Engineer / Desktop Application Developer
Key contribution

Combined collection, tabular analysis and configurable alerts in a Windows desktop tool, with later PyQt6 and embedded-browser development.

How the solution worked

  1. 01Load a property search
  2. 02Extract listing fields
  3. 03Filter and compare
  4. 04Apply monitoring rules
  5. 05Notify about matching advertisements

In this case study

  1. Structured property searches
  2. Monitoring and desktop development
← Back to CV

Structured property searches

Parsed listing pages into pandas tables with price, floor area, location and publication time. Added column filters, text search, numeric ranges and links back to the source advertisements.

Monitoring and desktop development

Implemented configurable checking intervals, background tasks and email notifications. Later development added PyQt6 and Qt WebEngine integration.
