Project in depth

Telecom data models aligned with TM Forum SID / ODA

Analysed Hyperoptic’s relational data structures and mapped them to TM Forum SID concepts. The aim was consistent meaning and relationships across telecom systems.

Client / context
Hyperoptic, UK · via Intuita Consulting
Period
During the Intuita engagement · September 2022 – February 2024
My role
Data Engineer / Data Modeller

In this detail

  1. Understanding the existing domain
  2. Mapping to SID and ODA
  3. Expressing relationships and integration options
  4. Contribution
← Project overview

Understanding the existing domain

Examined complex systems used by a fibre-broadband provider. Worked through their entities, relationships and operational purpose before mapping them to an industry information model.

Mapping to SID and ODA

Aligned existing structures with the Shared Information/Data model and related Open Digital Architecture concepts. Connected modelling choices with Hyperoptic’s operational objectives.

Expressing relationships and integration options

Produced ER and UML models with Sparx Enterprise Architect, PlantUML, Lucid and MySQL Workbench. Built integration prototypes showing how existing telecom systems could use the SID framework.

Contribution

The work provided domain mappings, explicit relationships and integration examples that supported consistent definitions of data across systems.
