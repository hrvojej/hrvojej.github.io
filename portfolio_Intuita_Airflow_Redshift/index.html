DataDQ: advertising data ingestion and Redshift processing

Developed Python and Airflow workflows to process advertising data in S3 and Redshift, including campaign-viewability updates and SQL cleaning of media-performance exports.

Advertising data prepared for reporting

Developed Python, Airflow and SQL processing for DataDQ during the Intuita engagement. The work brought advertising extracts into a warehouse structure suitable for comparing campaigns, placements, impressions, viewability and related performance measures.

The main implementation work covered S3 file processing, Redshift staging and updates, and the cleaning of advertising-performance exports. Airflow made the individual processing steps and their order explicit.

S3 files and Airflow orchestration

Built workflows that listed files under an S3 prefix, downloaded individual extracts for inspection and counted file lines. Defined separate tasks for preparing a staging table and loading the corresponding file into Redshift.

Organised file processing into an Airflow task group. The development included both an on-demand loading workflow and a scheduled version, with task dependencies and error-handling branches.

DoubleVerify viewability records and warehouse updates

Prepared DoubleVerify viewability data around seven reporting dimensions: campaign, media type, placement, date, brand, advertiser and media property. The associated measures were viewable impressions, measured impressions and viewability rate.

Implemented Redshift COPY loading for delimited files into a staging table. Used the reporting dimensions to match existing records, update their measures and insert records that were not already present.

Prepared SQL checks comparing the staged measures with the destination and counting campaign records after loading. These checks supported investigation of the loading and update logic.

Cleaning advertising-performance exports

Prepared SQL transformations for DSP performance reports. Standardised report dates and removed spreadsheet-style equals signs and quotation marks from advertiser, order, line-item and creative identifiers and names.

Converted percentage fields into numeric values so reporting could use viewability, measurability, click-through and invalid-traffic rates consistently. Preserved impressions, measurable and viewable impressions, clicks, invalid impressions and clicks, fees and costs alongside the reporting dimensions.
