Parsing · Data integration

A modular Python parser for audience-measurement data

Developed Python parsers and a PostgreSQL processing prototype for BARB panel viewing, daily advertising spots and audience-measurement reference data.

Client / context
Intuita Consulting, UK · BARB Audiences data formats
Period
During the Intuita engagement · September 2022 – February 2024
My role
Lead Data Engineer / Developer
Key contribution

Turned fixed-width file specifications into record layouts, parsing routines and relational tables. Added batch processing and diagnostics, and proposed an S3 and Snowflake pipeline as the next step.

  1. 01Audience file specification
  2. 02Python format parsers
  3. 03Structured records
  4. 04PostgreSQL prototype
  5. 05Proposed S3 / Snowflake ETL

From format specification to processing logic

Built separate modules for Panel Viewing (DSP01), Daily Spot Data (DSP04) and Master files (DSP14). Defined record layouts for viewing sessions, households, devices, advertising spots, channels, panels and other reference information.

A foundation for downstream ETL

Implemented fixed-position field extraction, parameterised SQL and upsert statements in a PostgreSQL prototype. Added a folder dispatcher, counts and development diagnostics, then prepared a proposal for an S3 and Snowflake ETL pipeline.
