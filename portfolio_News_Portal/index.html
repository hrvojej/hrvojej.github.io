News collection, AI summaries and web publishing

Built a news portal combining Python collection, PostgreSQL storage, Dagster jobs, structured AI summaries and generated article/category pages. Developed the project using Oracle Cloud.

Client / context
Independent news-portal project
Period
Independent development
My role
Data Architect / Full-Stack Developer
Key contribution

Connected source collection, structured analysis and web publishing in a single news-processing system.

How the solution worked

  1. 01Collect source articles
  2. 02Normalize and store
  3. 03Generate structured summaries
  4. 04Build article and category pages
  5. 05Publish the portal

In this case study

  1. Collection and data platform
  2. Summarisation and publishing
← Back to CV

Collection and data platform

Created source-specific RSS and HTML parsers, a shared PostgreSQL model and Dagster jobs for recurring collection and content updates.

Summarisation and publishing

Integrated structured LLM summaries with Jinja page generation, source attribution and category navigation. Implemented static publishing with Cloudflare R2 and Workers.
