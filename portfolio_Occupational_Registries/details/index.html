Project in depth

Web applications for occupational and professional registers

Developed web applications for maintaining Croatian occupational classifications and information about regulated professions. The applications combined relational data models, searchable registers, editing forms, user administration and change-history views.

Client / context
Croatian occupational classifications and regulated professions
Period
Public-sector register development
My role
Application & Data Developer

In this detail

  1. Occupational classifications and their relationships
  2. Regulated professions and supporting information
  3. Search, browsing and everyday editing
  4. Change-history views
  5. User administration and application structure
← Project overview

Occupational classifications and their relationships

Built an application for browsing and maintaining the 1998 and 2010 versions of Croatia’s National Classification of Occupations (NKZ 98 / NKZ 10). Records contained classification codes, names at different hierarchy levels and status information.

Implemented mappings between the two classification versions and the relevant Croatian Qualifications Framework (HKO) education fields, sectors and subsectors. Editing forms presented reference codes together with their names so that users could select the intended classification.

Regulated professions and supporting information

Built a separate application for maintaining regulated professions and profession groups. Related each record to occupational codes, sectors, subsectors, countries and regions.

The record model covered Croatian and English names, descriptions of professional activities, legal references, responsible authorities and information about qualification recognition. Structured forms brought these related details together for editing and review.

Search, browsing and everyday editing

Implemented list and detail views, multi-field text search and column-based sorting. Users could navigate from classification or profession lists to the associated details and edit the underlying records.

Used dedicated form models and database-backed selection lists for linked reference values. Added validation and checks to prevent deletion of an occupational record while it was still used by classification mappings.

Change-history views

Built views over audit records so that users could inspect the recorded action, editor and change time alongside the classification or profession data. Added searching and sorting to help locate changes.

Maintained separate current-data and audit models, including combined detail views that displayed the related classification and reference information.

User administration and application structure

Used ASP.NET Core MVC, Razor views and Entity Framework Core with SQL Server. Added identity, login and role-administration functionality, with public browsing where appropriate and authenticated access to editing functions.

Configured Croatian localisation and developed the forms, navigation and administrative views around the register workflow.
