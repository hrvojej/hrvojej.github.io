Croatia’s national register of regulated professions

Designed the database and developed the web application used to maintain Croatia’s national register of regulated professions. Combined structured profession records, qualification-recognition information, linked classifications, administrative forms, user access and change-history views in a C# / ASP.NET Core application backed by SQL Server.

National register and my contribution

The register maintains information about regulated professions across Croatia. A profession record needs more than a name: it must connect the professional activity with the applicable legal context, responsible bodies and information about recognising qualifications.

Designed the relational database and developed the application used to browse, enter, update and maintain this information. The work covered domain modelling, database-backed forms, search and detail screens, reference-data administration, user/role management and audit views.

Profession records and recognition information

Modelled Croatian and English profession names and descriptions together with profession groups and supporting reference records. The record structure included professional activities, legal references and the competent authorities relevant to the profession.

Included fields describing the qualification-recognition system, recognition conditions and the authority responsible for recognition. Keeping these as structured parts of the record made them available in the same maintenance workflow as the profession’s name and classification.

Relational reference data

Linked profession records to profession groups, occupational codes, sectors and subsectors. Added country and region reference data so that geographic information could be maintained consistently across records.

Used Entity Framework Core models and navigation relationships over SQL Server. Form models and selection lists connected stored identifiers to readable names, helping an editor choose the intended related record.

The application sits alongside separate occupational-classification work covering the National Classification of Occupations (NKZ) and Croatian Qualifications Framework (HKO). The national profession register has its own professional and recognition-related record structure.

Browsing, search and administrative editing

Built list, detail, create, edit and delete views for the profession and reference-data areas. The workflow allowed an editor to start from a searchable list, inspect a record and update its fields and related classifications.

Added multi-field text search and column-based sorting to support everyday register maintenance. Dedicated view models and database-backed selections kept the screens centred on the relevant profession, group and reference information.

Implemented the web interface using ASP.NET Core MVC and Razor, with HTML, CSS, JavaScript and Bootstrap for forms and navigation. Included a rich-text editor in the published interface for maintaining longer text.

Profession groups and linked detail views

Built separate list and detail components for profession groups as well as individual professions. The model distinguished stored group records from the combined views used to present their related details.

This structure supported maintenance of shared group information while preserving profession-specific activities and recognition requirements. A change to a reference record could be managed within the application rather than repeated manually in unrelated text fields.

Change history and traceable maintenance

Developed audit-list and detail views for professions and profession groups. These exposed the recorded action, editor and time alongside the relevant record information.

Provided search and sorting over the audit views so that maintainers could locate changes and review the associated details. Kept current-data models separate from the audit representations used for historical review.

Users, roles and localisation

Implemented login and user/role-administration functionality using ASP.NET Core Identity. Organised authenticated editing and administrative work around the register’s maintenance needs.

Configured Croatian localisation and included Croatian/English domain fields where the profession record required them. Application labels, linked names and administrative screens were designed for practical maintenance of Croatian national reference data.

Application delivery

Prepared a deployable ASP.NET Core application containing the register code, compiled Razor views, configuration structure and web assets. The published package used the .NET Core / ASP.NET Core 3.1 runtime and SQL Server integration through Entity Framework Core.

The delivered application brought database design and the maintenance interface together: structured profession information, linked reference data, authorised editing and reviewable changes could be handled within one system.
