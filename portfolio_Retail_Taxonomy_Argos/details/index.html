Argos: retail data collection and analytics

Built a complete Python application for collecting and analysing Argos retail data. It combines category discovery, product-link pagination and parsing of saved product pages, producing structured datasets with category, price, description, rating and review information.

Purpose and development context

Completed an application for the collection and analysis of Argos retail data during the Intuita engagement. It turns nested website navigation and individual product pages into a joined, reusable analytical dataset.

The application separates discovery, collection, parsing and tabular analysis. Intermediate exports make the category hierarchy and product information available for inspection at each stage.

Discovering the category hierarchy

The first stage uses Python and Playwright to collect visible top-level category names and links. Subsequent stages navigate those categories to extract subcategory headings and third-level links.

A further script collects fourth-level navigation where present. pandas.json_normalize converts the nested results into tables while retaining the parent category URL, allowing lower-level rows to be related to the original hierarchy.

Building a joined taxonomy dataset

Normalised category links and combined the level-two/three dataset with the fourth-level collection using a left join. This retains categories even where the deeper navigation is absent.

Prepared pipe-delimited CSV and Excel exports for intermediate levels and the combined taxonomy. The explicit intermediate outputs make it possible to inspect category discovery before collecting individual products.

Collecting product links across result pages

Implemented paginated category traversal and extracted product titles and links from the product-card elements. The script advances through numbered result pages and stops when the expected product elements are no longer found.

The browser collection code uses asynchronous Playwright, configurable viewports and image-request suppression to reduce unnecessary page content during extraction.

Parsing saved pages into product attributes

A separate asynchronous parser reads saved product-page content and extracts category levels, product title, rating, review count, price and description. It uses the relevant page labels and text boundaries to locate those fields.

The description parser collects content between the product-description section and the questions-and-answers section. Rating and review parsing include handling for values that cannot be converted or are absent.

Processing of multiple saved files is scheduled with asyncio and aiofiles. The resulting rows are assembled in a pandas DataFrame and exported to CSV and Excel.

Analytical datasets and output structure

The final record keeps the source filename alongside the category and product attributes, connecting a tabular result with the saved material from which it was extracted.

Joining product attributes to the category hierarchy gives the analysis a common structure: products can be examined by category together with their prices, ratings, review counts and descriptions. CSV and Excel outputs support tabular inspection and further analysis.
