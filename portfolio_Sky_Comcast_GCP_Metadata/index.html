Cloud prototype · Metadata / CDC

A tested prototype for database changes and cloud metadata

Designed, implemented and tested a service for capturing relational-database changes and transferring them into a highly available Google Cloud AlloyDB environment.

Client / context
Comcast / Sky Group / Sky UK · via Intuita Consulting
Period
During the Intuita engagement · September 2022 – February 2024
My role
Lead Engineer / Developer
Key contribution

Built and tested a prototype that captured database changes with PostgreSQL triggers and Python, then transferred them to AlloyDB. Designed the next integration steps for Dataplex and BigQuery.

How the solution worked

  1. 01Relational source changes
  2. 02SQL triggers / Python
  3. 03AlloyDB
  4. 04Metadata integration design
  5. 05Dataplex / BigQuery

In this case study

  1. Prototype objective

← Back to CV

Prototype objective

The prototype addressed changes to relational-database fields and their movement into a cloud environment for data/metadata management. It combined source capture, storage and downstream integration concerns.

Implementation and validation

Led development of the service and supporting Python scripts. Used PostgreSQL and SQL triggers to capture changes and worked with an AlloyDB cluster, Cloud Storage and Google Tasks.

Designed how captured changes would be passed to Dataplex and BigQuery. Tested real-time transfer of complex database changes and checked data integrity and availability within the prototype.

Prototype result

Delivered a working prototype with end-to-end tests of real-time change transfer, data integrity and availability, alongside the design for onward metadata integration into Dataplex and BigQuery.
