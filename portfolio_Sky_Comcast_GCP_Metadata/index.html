Sky / Comcast: schema-metadata capture on Google Cloud

Built and tested an AlloyDB prototype that captures table and column metadata changes for a Dataplex governance integration, using SQL event triggers, audit tables and Python.

Client / context
Comcast / Sky Group / Sky UK · via Intuita Consulting
Period
During the Intuita engagement · September 2022 – February 2024
My role
Lead Engineer / Developer
Key contribution

A tested metadata-capture prototype with catalogue extraction, DDL-triggered refresh and old/new change records.

How the solution worked

  1. 01AlloyDB database catalogue
  2. 02Table and column metadata
  3. 03DDL-triggered refresh
  4. 04Change audit
  5. 05Dataplex integration design

In this case study

  1. Prototype objective
  2. Implementation and validation
  3. Engineering output
← Back to CV

Prototype objective

Make changes to database schemas, tables and columns available as structured metadata for the Google Cloud governance environment.

Implementation and validation

Built metadata tables from information_schema, a refresh function triggered by DDL operations, and INSERT/UPDATE/DELETE audit functions with old/new values. Tested table creation and column changes in the AlloyDB prototype.

Engineering output

Delivered the metadata structures, refresh and audit logic, Python/SQL development work and the design for onward Dataplex integration. The engagement covered a tested prototype.
