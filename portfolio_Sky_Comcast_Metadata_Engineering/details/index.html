Project in depth

Turning Confluence documentation into structured metadata

Led a project to turn complex Confluence documentation into structured metadata. The source material described relational systems and database objects in forms that were not ready for direct analytical use.

Client / context
Comcast / Sky Group / Sky UK · via Intuita Consulting
Period
During the Intuita engagement · September 2022 – February 2024
My role
Lead Engineer / Developer

In this detail

  1. Understanding the documentation
  2. Extraction and restructuring
  3. Metadata storage and governance
  4. Knowledge transfer
← Project overview

Understanding the documentation

Analysed the meaning and organisation of descriptions before designing extraction. Developed processing approaches suited to the different documentation forms.

Extraction and restructuring

Developed Python processing and scripts to extract and organise the information. Systematised object descriptions and prepared representations suitable for storage and retrieval.

Metadata storage and governance

Used SQL and PostgreSQL for data manipulation and relational storage, with Collibra in the metadata-management context. Connected extracted information with structures that could be queried and reused.

Knowledge transfer

Presented the project and technical approach to the Sky Italy team. The team subsequently adopted a similar solution, extending the use of the approach beyond the original engagement.

Technology & methods

  • Python
  • SQL
  • Confluence
  • PostgreSQL
  • Collibra
