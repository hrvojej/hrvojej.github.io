Metadata engineering · Governance

Turning Confluence documentation into structured metadata

Turned Confluence descriptions of databases and their objects into structured metadata that could be stored, searched and reused.

Client / context
Comcast / Sky Group / Sky UK · via Intuita Consulting
Period
During the Intuita engagement · September 2022 – February 2024
My role
Lead Engineer / Developer
Key contribution

Converted unstructured system documentation into reusable metadata with Python, SQL, PostgreSQL and Collibra. Presented the approach to Sky Italy, which subsequently adopted a similar solution.

How the solution worked

  1. 01Confluence documentation
  2. 02Interpretation & extraction
  3. 03Structured metadata model
  4. 04PostgreSQL / Collibra
  5. 05Reuse & knowledge transfer

In this case study

  1. A documentation-to-data problem
  2. Extraction, modelling and storage
  3. Knowledge transfer and reuse
← Back to CV

A documentation-to-data problem

The source was complex system and object documentation rather than an already normalised metadata feed. The task required interpreting meaning and structure before reliable extraction and modelling were possible.

Extraction, modelling and storage

Led the project and developed multiple extraction/processing approaches for different documentation forms. Systematised descriptions and prepared relational and other data representations suitable for retrieval and reuse.

Implemented Python processing and scripts, SQL queries and data manipulation, using PostgreSQL and Collibra in the metadata/governance context.

Knowledge transfer and reuse

Presented the solution and technical approach to the Sky Italy team, supporting knowledge transfer across organisations. Sky Italy subsequently adopted and implemented a similar solution.

Technology & methods

  • Python
  • SQL
  • PostgreSQL
  • Confluence
  • Collibra Data Intelligence Platform
