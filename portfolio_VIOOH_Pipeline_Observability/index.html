A cross-platform view of pipeline behaviour

The application brought together checks over the data lake and warehouse. That made it possible to investigate deviations across the processing chain rather than treating each storage layer independently.

Implementation

Designed and implemented the cloud web application using Python and SQL. Used S3/data-lake inputs, Athena access, Lambda execution, Glue and API components, together with Snowflake external-service integrations.

Connected anomaly detection and notifications to operational monitoring needs. Specific notification channels and separate business-impact percentages are not required to describe the delivered capability.

Practical value

Shows the ability to build targeted operational tools when standard platform monitoring is insufficient to explain a data-quality or pipeline issue. It complements the SQL/dbt engineering work on the main advertising-data flow.
