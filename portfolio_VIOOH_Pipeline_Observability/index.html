Pipeline anomaly detection and operational notifications

Built a cloud application that checked data in the lake and warehouse, detected anomalies and notified the operations team when investigation was needed.

Client / context
VIOOH / JCDecaux · via Intuita Consulting, UK
Period
During the Intuita engagement · September 2022 – February 2024
My role
Application Designer / Developer
Key contribution

Built an application combining data-lake and warehouse checks with anomaly notifications, helping operations teams identify deviations requiring investigation.

A cross-platform view of pipeline behaviour

The application brought together checks over the data lake and warehouse. That made it possible to investigate deviations across the processing chain rather than treating each storage layer independently.

Implementation

Designed and implemented the cloud web application using Python and SQL. Used S3/data-lake inputs, Athena access, Lambda execution, Glue and API components, together with Snowflake external-service integrations.

Connected anomaly detection and notifications to operational monitoring so deviations requiring intervention became visible across the processing chain.

Practical value

Extended operational monitoring with application-level checks over data in both the lake and warehouse, complementing SQL/dbt engineering on the main advertising-data flow.
