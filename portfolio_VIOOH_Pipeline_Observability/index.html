Data reliability · Cloud application

Pipeline anomaly detection and operational notifications

Built a cloud application that checked data in the lake and warehouse, detected anomalies and notified the operations team when investigation was needed.

Client / context
VIOOH / JCDecaux · via Intuita Consulting, UK
Period
During the Intuita engagement · September 2022 – February 2024

Connecting lake and warehouse checks

Used S3 and Athena to access data in the lake and integrated Snowflake services into the checking process. This gave the application information from more than one stage of processing.

Implementing the cloud application

Developed Python and SQL processing with Lambda, Glue and API components. Combined these components in a web application for reviewing anomalies and producing notifications.

Snowflake-to-Lambda notification integration

Implemented a Lambda handler compatible with the Snowflake external-function request format. It reads a JSON body containing an array of input rows and preserves each row number in the response so the calling system can associate results with requests.

The input fields carry the recipient and the market, deal, unit, trade hour and pacing value needed to describe an underpacing condition. The handler processes each row and returns the corresponding result in a JSON data array.

Constructing an actionable pacing message

Used Amazon SES through boto3 to build an email describing the affected deal and period. The message includes the pacing measure as sold impressions relative to expected impressions, together with the market and unit context.

The implementation supplies HTML and plain-text bodies, handles SES client errors and returns HTTP status information to the caller. Earlier handler material also explores a query-parameter API interface.
